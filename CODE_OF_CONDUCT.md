# 📜 Code of Conduct

## 🌟 Our Commitment

We as contributors and maintainers of **Schedula** pledge to make participation in our community a respectful, inclusive, and harassment-free experience for everyone.

We are committed to creating an open-source environment where everyone feels welcome regardless of:
- Experience level
- Gender
- Age
- Nationality
- Personal background
- Identity
- Appearance
- Religion
- Technical expertise

---

# 🤝 Expected Behavior

All contributors are expected to:

- Be respectful and supportive
- Use welcoming and inclusive language
- Accept constructive feedback gracefully
- Help beginners and new contributors
- Focus on collaboration and learning
- Maintain professionalism in discussions
- Respect differing opinions and experiences

---

# 🚫 Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or discrimination of any kind
- Personal attacks or insulting comments
- Hate speech or offensive language
- Trolling or deliberately disruptive behavior
- Sharing private information without consent
- Spam or self-promotion unrelated to the project
- Plagiarism or intentionally harmful contributions

---

# ⚠️ AI Usage Policy

AI tools are allowed for:
- Learning concepts
- Understanding code
- Debugging assistance
- Documentation help
- Improving productivity

However:

❌ Blindly copy-pasting large amounts of AI-generated code without understanding it is discouraged.

Contributors should:
- Understand the code they submit
- Be able to explain their implementation
- Ensure code quality and maintainability
- Follow project architecture and standards

Maintainers reserve the right to reject low-quality or irresponsible AI-generated contributions.

---

# 💬 Communication Guidelines

Please keep all interactions:
- Friendly
- Professional
- Constructive
- Inclusive

When reviewing pull requests:
- Give actionable feedback
- Avoid harsh criticism
- Encourage learning and improvement

Project maintainers are responsible for enforcing this Code of Conduct.

They may:
- Remove inappropriate content
- Reject harmful pull requests

Actions will be taken based on the severity and frequency of violations.
